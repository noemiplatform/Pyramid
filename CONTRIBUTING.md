# CONTRIBUTING

## Contribution Policy

This project is maintained exclusively by the owner **noemiplatform** (Noemi Platform CAP).

**External contributions are not accepted at this time.**

### Why?

Pyramid is an experimental mathematical system with strict architectural requirements. To maintain system integrity and design coherence, changes are only made by the core team.

### Can I use this code?

Yes. The project is open source under the MIT license. You are welcome to:

- Use it in your own projects
- Study and learn from the code
- Fork it for your own experimentation

### Can I contribute?

No. This repository does not accept:

- Pull requests
- Code contributions
- Feature requests via PRs

### Questions or feedback?

Open an issue if you have questions, but note that we cannot guarantee responses or merges.
