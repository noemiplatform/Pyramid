# Security & Access Control

## Repository Policy

This repository is protected and controlled by the owner **noemiplatform** (Noemi Platform CAP).

### Access Rules

- **Owner Only:** Only `noemiplatform` can make direct commits, merge PRs, and modify the codebase
- **No Forking:** External forking is disabled
- **No External PRs:** Pull requests from external contributors will not be merged
- **Branch Protection:** The `main` branch is protected and requires owner approval for any changes

### How Changes Are Made

1. All changes must be initiated by or approved by `noemiplatform`
2. No external contributors can push to `main`
3. All branches require review before merge
4. Direct commits to `main` are the only allowed merge path

### Contribution Policy

This project is a proprietary mathematical system and design tool.

- External contributions are **not accepted**
- The codebase is maintained solely by the owner
- Issues and discussions may be opened but will not result in merged code from external parties

### Contact

For inquiries about this project, contact the owner directly.
