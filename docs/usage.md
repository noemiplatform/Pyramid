# Pyramid Usage Guide

## Install

```bash
npm install
```

## Run tests

```bash
npm test
```

## CLI examples

```bash
node src/index.js multiply 1 1
node src/index.js square 3
node src/index.js table 5
node src/index.js matrix 3 4
node src/index.js pattern 8
node src/index.js spec
```

## Browser visualizer

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/web/
```

## Example result

```text
node src/index.js multiply 3 3
6
```

## Notes

Pyramid is designed to be concept-first and creative. While it is not conventional arithmetic, it gives you a reliable framework to prototype alternate numeric systems and transform them into design patterns, experiments, or visual components.
